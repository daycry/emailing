### Added — `proveedores-email` initiative (2026-10-30)

- **T-01 — Account provider settings** Encrypted Brevo and SendGrid profiles per account, with separate authorization for external senders.
- **T-02 — Shared transport contracts** API acceptance, SMTP acceptance and later provider feedback have distinct representations.
- **T-03 — Brevo and SendGrid SMTP** TLS delivery adapters classify observed rejections and block EHLO downgrade.
- **T-04 — Brevo and SendGrid APIs** Bounded responses and no automatic resend after uncertain acceptance.
- **T-05 — Provider feedback** Authenticated, deduplicated webhooks record feedback separately and apply account suppressions.
- **T-06 — Application integration** Provider settings and activity integrate with campaigns, the API and MCP.
- **T-07 — Complete user manual** Markdown and PDF cover installation from scratch, usage and administration, with examples and Mermaid diagrams.
